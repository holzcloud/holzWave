# The one list of permissions the Android app may ask for, one per line. Lines that start with # are comments.
#
# The manifest (app/src-tauri/gen/android/app/src/main/AndroidManifest.xml) must hold exactly these permissions, no more and no
# fewer. The text test android_release and the APK check scripts/android-apk-check.sh both read this file, so a permission that is
# added anywhere else fails one of them. A feature that needs a permission adds its line here in the same commit as the line in
# the manifest, and says in the commit message what the permission is for. Nothing that installs packages, reads the screen,
# draws over other apps or reads contacts, messages or location belongs here.
#
# Not listed on purpose: a permission that the app itself defines with signature protection (the one AndroidX adds so that only
# the app can send a broadcast to its own receivers, named <application id>.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION). It is not
# in the manifest of the project but in the merged manifest of a built APK, and the APK check accepts exactly that name.
android.permission.INTERNET
# The foreground service that keeps shells and SSH connections running while the app is in the background: the service itself,
# its type specialUse, and the notification it must show (asked once on Android 13 and later; a denial keeps the service).
android.permission.FOREGROUND_SERVICE
android.permission.FOREGROUND_SERVICE_SPECIAL_USE
android.permission.POST_NOTIFICATIONS
# The system prompt that opens the secret store (the screen lock or a fingerprint or face): the framework BiometricPrompt, which
# the platform asks every app to declare this permission for. It reads no biometric data; the system does the check.
android.permission.USE_BIOMETRIC
# Reaching a device on the local network (a private address: a NAS, a home server, another computer on the same Wi-Fi) on Android 17
# and later, where an app that targets it needs this runtime permission and a connection without it times out. It is asked, with the
# system's own dialog, when the first connection to such an address is made and never at the start; below Android 17 it does not exist.
android.permission.ACCESS_LOCAL_NETWORK
